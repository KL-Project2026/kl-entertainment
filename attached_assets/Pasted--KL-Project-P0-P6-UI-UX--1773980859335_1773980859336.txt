## PHASE T1 — DB 상태 검증

아래 SQL을 모두 실행하고 결과를 기록하세요.

### T1-A. 테이블 존재 확인

```sql
SELECT table_name,
  (SELECT COUNT(*) FROM information_schema.columns
   WHERE table_name = t.table_name) AS column_count
FROM information_schema.tables t
WHERE table_schema = 'public'
  AND table_name IN (
    'reservations','guests','rooms','tables','users',
    'hostesses','agents','folio_entries','invoices',
    'payments','receipts','hostess_sessions',
    'hostess_payouts','agent_commissions','expenses',
    'attendance','availability_blocks','staff_schedules'
  )
ORDER BY table_name;
```

**기대 결과**: 18개 테이블 모두 표시
**오류 처리**: 누락된 테이블은 P1 SQL을 즉시 재실행

---

### T1-B. 필수 컬럼 확인

```sql
-- reservations: room_id nullable 여부
SELECT column_name, is_nullable, data_type
FROM information_schema.columns
WHERE table_name = 'reservations'
  AND column_name IN ('room_id','table_id','assigned_at','assigned_by');

-- attendance: 필수 컬럼 확인
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'attendance'
ORDER BY ordinal_position;

-- availability_blocks: 인덱스 확인
SELECT indexname FROM pg_indexes
WHERE tablename = 'availability_blocks';
```

**오류 처리**:
- `room_id`가 NOT NULL이면: `ALTER TABLE reservations ALTER COLUMN room_id DROP NOT NULL;`
- 누락 컬럼이 있으면: `ALTER TABLE [table] ADD COLUMN IF NOT EXISTS [col] [type];`

---

### T1-C. 트리거 및 함수 확인

```sql
-- 트리거 확인
SELECT trigger_name, event_object_table, action_timing, event_manipulation
FROM information_schema.triggers
WHERE trigger_schema = 'public';

-- 함수 확인
SELECT routine_name, routine_type
FROM information_schema.routines
WHERE routine_schema = 'public'
  AND routine_name IN (
    'calc_hours_worked',
    'generate_invoice_no',
    'generate_receipt_no'
  );
```

**오류 처리**: 없는 함수/트리거는 P1 SQL 재실행

### T1-D. 테스트 데이터 최소 확인

```sql
SELECT 'reservations'    AS tbl, COUNT(*) AS cnt FROM reservations
UNION ALL
SELECT 'guests',          COUNT(*) FROM guests
UNION ALL

UNION ALL
SELECT 'users',           COUNT(*) FROM users
```

**기대**: 각 테이블에 1건 이상

### T2-D. API 응답 테스트

각 API를 실제로 호출하여 응답 확인:

```javascript
// 백엔드 테스트 스크립트 — 임시 파일로 실행
// test_api.js (테스트 후 삭제)

const BASE = 'http://localhost:3000'; // ⚠️ 실제 포트로 교체

const tests = [
  { method:'GET',  url:'/api/invoices',            expect: 200 },
  { method:'GET',  url:'/api/accounts/daily',       expect: 200 },
  { method:'GET',  url:'/api/availability/rooms?start_dt=2025-01-01T18:00:00&end_dt=2025-01-01T22:00:00', expect: 200 },
  { method:'POST', url:'/api/availability/check',
    body:{ entity_type:'room', entity_id:1,
           start_dt:'2025-06-01T18:00:00', end_dt:'2025-06-01T22:00:00' },
    expect: 200 },
];

async function runTests() {
  console.log('=== API 응답 테스트 시작 ===');
  for (const t of tests) {
    try {
      const opts = {
        method: t.method,
        headers: { 'Content-Type': 'application/json' },
      };
      if (t.body) opts.body = JSON.stringify(t.body);
      const res = await fetch(BASE + t.url, opts);
      const status = res.status === t.expect ? '✅' : '❌';
      console.log(`${status} ${t.method} ${t.url} → ${res.status}`);
    } catch (err) {
      console.log(`❌ ${t.method} ${t.url} → ERROR: ${err.message}`);
    }
  }
  console.log('=== 완료 ===');
}

runTests();
```

```jsx
// 파일 상단에 추가 (이미 있으면 SKIP)
const fmtDate = (v) => {
  if (!v) return '—';
  try {
    return new Date(v).toLocaleDateString('th-TH', {
      day: '2-digit', month: 'short', year: 'numeric',
    });
  } catch { return String(v); }
};

// ISO 문자열이 직접 렌더링되는 부분을 교체:
// BEFORE: {item.created_at}
// AFTER:  {fmtDate(item.created_at)}
```

```jsx
const fmtCurrency = (amount, currency = 'THB') => {
  if (amount == null) return '—';
  try {
    return new Intl.NumberFormat('th-TH', {
      style: 'currency', currency,
      minimumFractionDigits: 0, maximumFractionDigits: 0,
    }).format(amount);
  } catch { return `${currency} ${Number(amount).toFixed(0)}`; }
};
```
