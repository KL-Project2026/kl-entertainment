## 🔒 CRITICAL SAFETY RULES — 반드시 먼저 읽고 따를 것

```
SAFETY RULE 1 — READ FIRST, WRITE SECOND
  모든 파일을 수정하기 전에 반드시 전체 내용을 먼저 읽어라.
  읽지 않은 파일은 절대 덮어쓰지 마라.

SAFETY RULE 2 — SYNTAX VALIDATION BEFORE SAVE
  코드 작성 후 저장 전에 반드시 문법 오류를 검증하라.
  - JSX: 닫히지 않은 태그, 빠진 쉼표, 잘못된 props 확인
  - JS/TS: 선언되지 않은 변수, 잘못된 import 확인
  - CSS: 닫히지 않은 중괄호 확인
  오류가 하나라도 있으면 저장하지 말고 수정 후 재검증하라.

SAFETY RULE 3 — NEVER DELETE EXISTING CODE
  기존 함수, 라우트, 컴포넌트를 절대 삭제하지 마라.
  기존 코드를 "교체"가 아닌 "확장"하는 방식으로 작성하라.
  새 기능은 기존 코드 옆에 추가하되, 기존 로직은 유지하라.

SAFETY RULE 4 — IMPORT PATH VERIFICATION
  새 컴포넌트나 함수를 import할 때:
  - 해당 파일이 실제로 존재하는지 먼저 확인하라.
  - 경로가 정확한지 확인하라 (대소문자 포함).
  - 존재하지 않는 파일에서 import하지 마라.

SAFETY RULE 5 — ONE FILE AT A TIME
  파일 하나를 완전히 완료하고 검증한 뒤에 다음 파일로 이동하라.
  에러가 발생하면 즉시 멈추고 보고하라. 에러를 무시하고 진행하지 마라.

SAFETY RULE 6 — SHARED COMPONENT STRATEGY
  공통 컴포넌트(검색, 뷰 토글, 배지 등)는 새 파일에 작성하라.
  기존 컴포넌트 파일 내부를 직접 수정하기 전에 해당 파일을 읽어라.

SAFETY RULE 7 — TEST BEFORE CLAIMING DONE
  각 파일 수정 완료 후 다음을 확인하라:
  - 앱이 여전히 실행되는가?
  - 기존 기능이 여전히 작동하는가?
  - 새 기능이 의도대로 동작하는가?
  확인 없이 "완료"라고 보고하지 마라.

// src/utils/formatters.js
// ─────────────────────────────────────────────────────────
// SHARED FORMATTERS — used across all list & detail pages
// MIGRATION NOTE: convert to TypeScript utilities in .NET/React production
// ─────────────────────────────────────────────────────────

/**
 * Format ISO date string → "15 Mar 2025"
 */
export const formatDate = (value) => {
  if (!value) return '—';
  try {
    return new Date(value).toLocaleDateString('en-GB', {
      day: '2-digit',
      month: 'short',
      year: 'numeric',
    });
  } catch {
    return String(value);
  }
};

/**
 * Format date + time → "15 Mar 2025, 14:30"
 */
export const formatDateTime = (value) => {
  if (!value) return '—';
  try {
    return new Date(value).toLocaleString('en-GB', {
      day: '2-digit',
      month: 'short',
      year: 'numeric',
      hour: '2-digit',
      minute: '2-digit',
    });
  } catch {
    return String(value);
  }
};

/**
 * Format currency → "฿ 4,500.00" or "$ 580.00"
 */
export const formatCurrency = (amount, currencyCode = 'USD') => {
  if (amount == null || amount === '') return '—';
  try {
    return new Intl.NumberFormat('en-US', {
      style: 'currency',
      currency: currencyCode,
      minimumFractionDigits: 2,
      maximumFractionDigits: 2,
    }).format(amount);
  } catch {
    return `${currencyCode} ${Number(amount).toFixed(2)}`;
  }
};

/**
 * Truncate long text with ellipsis
 */
export const truncate = (str, maxLength = 40) => {
  if (!str) return '—';
  return str.length > maxLength ? str.slice(0, maxLength) + '…' : str;
};

/**
 * Safe display — never show null/undefined/"null"/"undefined"
 */
export const display = (value) => {
  if (value == null || value === '' || value === 'null' || value === 'undefined') return '—';
  return String(value);
};
```

  const [filterValue, setFilterValue] = useState('');

  // ── Filter & Search logic ──────────────────────────────────────
  const filteredData = useMemo(() => {
    let result = [...data];

    // Type/status dropdown filter
    if (filterValue && filterKey) {
      result = result.filter((item) =>
        String(item[filterKey] || '').toLowerCase() === filterValue.toLowerCase()
      );
    }

    // Search filter — searches across searchKeys
    if (searchQuery.trim()) {
      const q = searchQuery.toLowerCase();
      result = result.filter((item) => {
        if (searchKeys.length > 0) {
          return searchKeys.some((key) =>
            String(item[key] || '').toLowerCase().includes(q)
          );
        }
        // Fallback: search all string fields
        return Object.values(item).some((val) =>
          String(val || '').toLowerCase().includes(q)
        );
      });
    }

    return result;
  }, [data, filterValue, filterKey, searchQuery, searchKeys]);

  return (
    <div style={{ padding: '24px', maxWidth: '1400px', margin: '0 auto' }}>

      {/* ── PAGE HEADER ── */}
      <div style={{
        display: 'flex',
        justifyContent: 'space-between',
        alignItems: 'center',
        marginBottom: '20px',
        flexWrap: 'wrap',
        gap: '12px',
      }}>
        <div>
          <h1 style={{ fontSize: '22px', fontWeight: 700, color: '#111827', margin: 0 }}>
            {title}
          </h1>
          <p style={{ fontSize: '13px', color: '#6b7280', margin: '4px 0 0' }}>
            {isLoading ? 'Loading...' : `${filteredData.length} record${filteredData.length !== 1 ? 's' : ''}`}
            {data.length !== filteredData.length && ` (filtered from ${data.length})`}
          </p>
        </div>

        <div style={{ display: 'flex', alignItems: 'center', gap: '10px', flexWrap: 'wrap' }}>
          {actions}
          {onAddNew && (
            <button
              onClick={onAddNew}
              style={{
                padding: '9px 18px',
                background: '#6366f1',
                color: '#ffffff',
                border: 'none',
                borderRadius: '8px',
                fontSize: '14px',
                fontWeight: 600,
                cursor: 'pointer',
                transition: 'background 0.15s ease',
              }}
              onMouseEnter={(e) => e.target.style.background = '#4f46e5'}
              onMouseLeave={(e) => e.target.style.background = '#6366f1'}
            >
              {addNewLabel || '+ Add New'}
            </button>
          )}
        </div>
      </div>

      {/* ── TOOLBAR: Search + Filter + View Toggle ── */}
      <div style={{
        display: 'flex',
        alignItems: 'center',
        gap: '12px',
        marginBottom: '16px',
        flexWrap: 'wrap',
        padding: '12px 16px',
        background: '#f9fafb',
        borderRadius: '10px',
        border: '1px solid #e5e7eb',
      }}>
        <SearchInput
          value={searchQuery}
          onChange={setSearchQuery}
          placeholder={searchPlaceholder || `Search ${title?.toLowerCase()}...`}
        />

        {filterKey && filterOptions && (
          <FilterDropdown
            label={filterLabel || filterKey}
            value={filterValue}
            options={filterOptions}
            onChange={setFilterValue}
          />
        )}

        {/* Clear filters button — only shown when filters active */}
        {(searchQuery || filterValue) && (
          <button
            onClick={() => { setSearchQuery(''); setFilterValue(''); }}
            style={{
              padding: '8px 12px',
              background: 'transparent',
              border: '1px solid #d1d5db',
              borderRadius: '8px',
              fontSize: '12px',
              color: '#6b7280',
              cursor: 'pointer',
            }}
          >
            ✕ Clear
          </button>
        )}

        <div style={{ marginLeft: 'auto' }}>
          <ViewToggle view={viewMode} onChange={setViewMode} />
        </div>
      </div>

      {/* ── CONTENT AREA ── */}
      {isLoading ? (
        <LoadingState />
      ) : filteredData.length === 0 ? (
        <EmptyState onAddNew={onAddNew} addNewLabel={addNewLabel} />
      ) : viewMode === 'table' ? (
        <TableView
          columns={columns}
          data={filteredData}
          onRowClick={onRowClick}
        />
      ) : (
        <CardView
          data={filteredData}
          cardRenderer={cardRenderer}
          onRowClick={onRowClick}
        />
      )}

    </div>
  );
};

export default ListPageWrapper;

## ⚠️ IF ERRORS OCCUR

```
에러 발생 시 처리 규칙:

1. SYNTAX ERROR in a component file
   → 수정한 내용을 원래대로 되돌린다
   → 에러 내용과 파일명을 보고한다
   → 해당 파일은 건너뛰고 다음 파일로 진행한다

2. IMPORT PATH ERROR
   → 에러 메시지를 보고한다
   → 해당 import 경로를 실제 파일 경로로 수정한다
   → 수정 후 다시 검증한다

3. ROUTE NOT FOUND for detail page
   → onRowClick을 추가하지 않는다
   → "Route missing: /[entity]/:id — skipped onRowClick" 으로 보고한다

4. API ENDPOINT NOT FOUND for Edit save
   → handleEdit 함수를 빈 Promise.resolve()로 대체한다
   → "Edit API endpoint unknown for [entity] — placeholder used" 로 보고한다

5. APP CRASHES after change
   → 즉시 해당 파일의 변경 내용을 원복한다
   → 크래시 원인을 보고한다
   → 절대 크래시 상태로 다음 단계를 진행하지 않는다
```
