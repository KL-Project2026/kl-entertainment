## Edit 추가 공통 패턴

각 상세 페이지 파일을 읽고, 아래를 기존 코드에 추가하세요.

### Step 1: 상태 추가 (기존 state 선언 아래)

```jsx
// ── Edit 상태 ─────────────────────────────────────────────
// 기존 state 아래에 추가
const [isEditMode, setIsEditMode] = useState(false);
const [editData,   setEditData]   = useState({});
const [isSaving,   setIsSaving]   = useState(false);
const [saveError,  setSaveError]  = useState(null);
```

### Step 2: Edit 함수 추가 (기존 함수 아래)

```jsx
// ── Edit 함수 ─────────────────────────────────────────────
const handleEditStart = () => {
  setEditData({ ...(record || {}) });
  setSaveError(null);
  setIsEditMode(true);
};

const handleEditCancel = () => {
  setIsEditMode(false);
  setEditData({});
  setSaveError(null);
};

const handleFieldChange = (key, value) => {
  setEditData(prev => ({ ...prev, [key]: value }));
};

const handleSave = async () => {
  setIsSaving(true);
  setSaveError(null);
  try {
    // ⚠️ API 경로를 실제 엔드포인트로 교체
    // P0에서 확인한 PUT 엔드포인트 사용
    // 없으면 console.log(editData) 만 실행하고 보고
    const res = await fetch(`/api/[entity]/${id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(editData),
    });
    if (!res.ok) {
      const d = await res.json();
      throw new Error(d.error || '저장에 실패했습니다.');
    }
    const updated = await res.json();
    setRecord(updated);   // ⚠️ 기존 record setter 이름으로 교체
    setIsEditMode(false);
  } catch (err) {
    setSaveError(err.message);
  } finally {
    setIsSaving(false);
  }
};
```

### Step 3: 헤더에 Edit 버튼 추가

기존 헤더 영역(Back 버튼이 있는 곳)에서, Back 버튼 **오른쪽**에 추가합니다.

```jsx
{/* 기존 헤더 JSX 유지 — Back 버튼 옆에 아래 블록 추가 */}
<div style={{ display:'flex', gap:8, alignItems:'center' }}>
  {saveError && (
    <span style={{ fontSize:12, color:'#dc2626' }}>⚠ {saveError}</span>
  )}

  {isEditMode ? (
    <>
      <button
        onClick={handleEditCancel}
        style={{
          padding:'8px 16px',
          background:'#ffffff',
          color:'#374151',
          border:'1px solid #d1d5db',
          borderRadius:8,
          fontSize:13,
          cursor:'pointer',
        }}
      >
        취소
      </button>
      <button
        onClick={handleSave}
        disabled={isSaving}

          padding:'8px 16px',
          background: isSaving ? '#d4b86a' : '#D1AE38',
          color:'#ffffff',
          border:'none',
          borderRadius:8,
```

### Step 4: 필드 영역 View / Edit 토글

### Step 5: EditField 헬퍼 컴포넌트 추가

각 상세 페이지 파일 **상단 (컴포넌트 함수 정의 위)** 에 추가합니다.

```jsx
// ── EditField helper (파일 상단에 추가) ───────────────────
const EditField = ({ label, value, type = 'text', options = [], onChange }) => (
  <div>
    <label style={{
      display:'block',
      fontSize:11,
      fontWeight:600,
      color:'#6b7280',
      textTransform:'uppercase',
      letterSpacing:'0.07em',
      marginBottom:5,
    }}>
      {label}
    </label>

    {type === 'select' ? (
      <select
        value={value}
        onChange={e => onChange(e.target.value)}
        style={EF_STYLE}
      >
        {options.map(opt => (
          <option key={opt.value ?? opt} value={opt.value ?? opt}>
            {opt.label ?? opt}
          </option>
        ))}
      </select>
    ) : type === 'textarea' ? (
      <textarea
        value={value}
        onChange={e => onChange(e.target.value)}
        rows={3}
        style={{ ...EF_STYLE, resize:'vertical', height:'auto' }}
      />
    ) : (
      <input
        type={type === 'date' ? 'date' : type === 'number' ? 'number' : 'text'}
        value={value}
        onChange={e => onChange(e.target.value)}
        style={EF_STYLE}
      />
    )}
  </div>
);

const EF_STYLE = {
  width:'100%',
  padding:'9px 12px',
  border:'1px solid #d1d5db',
  borderRadius:8,
  fontSize:14,
  color:'#111827',
  background:'#ffffff',
  outline:'none',
  boxSizing:'border-box',
};
```

### InvoiceList.jsx

```jsx
import { useState, useEffect } from 'react';
import { useNavigate } from 'react-router-dom';
import { useHoverRow } from '../utils/useHoverRow';
// ⚠️ 경로 조정

function InvoiceList() {
  const [invoices, setInvoices] = useState([]);
  const [loading,  setLoading]  = useState(true);
  const navigate = useNavigate();
  const { hoverProps, rowStyle } = useHoverRow();

  useEffect(() => {
    fetch('/api/invoices')
      .then(r => r.json())
      .then(d => { setInvoices(Array.isArray(d) ? d : []); setLoading(false); })
      .catch(() => setLoading(false));
  }, []);

  const fmt = (amount, currency='THB') => {
    if (amount==null) return '—';
    try { return new Intl.NumberFormat('th-TH',{style:'currency',currency,minimumFractionDigits:0}).format(amount); }
    catch { return `${currency} ${amount}`; }
  };

  const fmtDate = (v) => v ? new Date(v).toLocaleDateString('th-TH',{day:'2-digit',month:'short',year:'numeric'}) : '—';

  const STATUS_BADGE = {
    paid:          { bg:'#dcfce7', color:'#166534', label:'결제완료' },
    partially_paid:{ bg:'#fef9c3', color:'#854d0e', label:'부분결제' },
    issued:        { bg:'#dbeafe', color:'#1e40af', label:'발행' },
    draft:         { bg:'#f3f4f6', color:'#6b7280', label:'초안' },
    void:          { bg:'#fee2e2', color:'#991b1b', label:'취소' },
  };

  if (loading) return <div style={{padding:60,textAlign:'center',color:'#9ca3af'}}>Loading...</div>;

  return (
    <div style={{maxWidth:1200,margin:'0 auto',padding:24}}>
      <div style={{display:'flex',justifyContent:'space-between',
        alignItems:'center',marginBottom:24}}>
        <div>
          <h1 style={{fontSize:22,fontWeight:700,color:'#111827',margin:0}}>인보이스</h1>
          <p style={{fontSize:13,color:'#6b7280',margin:'4px 0 0'}}>{invoices.length}건</p>
        </div>
      </div>

      <div style={{overflowX:'auto',borderRadius:10,border:'1px solid #e5e7eb'}}>
        <table style={{width:'100%',minWidth:700,borderCollapse:'collapse'}}>
          <thead>
            <tr style={{background:'#f9fafb'}}>
              {['Invoice No','예약 Ref','발행일','금액','상태'].map(h=>(
                <th key={h} style={{padding:'10px 14px',fontSize:11,color:'#6b7280',
                  textAlign:'left',textTransform:'uppercase',letterSpacing:'0.06em',
                  fontWeight:600,borderBottom:'1px solid #e5e7eb',whiteSpace:'nowrap'}}>{h}</th>
              ))}
            </tr>
          </thead>
          <tbody>
            {invoices.length === 0 ? (
              <tr><td colSpan={5} style={{padding:40,textAlign:'center',color:'#9ca3af'}}>
                인보이스 없음
              </td></tr>
            ) : invoices.map(inv => {
              const s = STATUS_BADGE[inv.status] || {bg:'#f3f4f6',color:'#374151',label:inv.status};
              return (
                <tr key={inv.id}
                  {...hoverProps(inv.id)}
                  style={rowStyle(inv.id)}
                  onClick={()=>navigate(`/invoices/${inv.id}`)}>
                  <td style={{padding:'12px 14px',fontWeight:700,
                    fontFamily:'monospace',fontSize:13}}>{inv.invoice_no}</td>
                  <td style={{padding:'12px 14px',fontSize:13,color:'#6b7280'}}>
                    {inv.booking_ref||'—'}</td>
                  <td style={{padding:'12px 14px',fontSize:13}}>{fmtDate(inv.issued_at)}</td>
                  <td style={{padding:'12px 14px',fontSize:13,fontWeight:600}}>
                    {fmt(inv.total_amount,inv.currency)}</td>
                  <td style={{padding:'12px 14px'}}>
                    <span style={{background:s.bg,color:s.color,padding:'2px 10px',
                      borderRadius:9999,fontSize:11,fontWeight:600}}>{s.label}</span>
                  </td>
                </tr>
              );
            })}
          </tbody>
        </table>
      </div>
    </div>
  );
}

export default InvoiceList;
```

```jsx
        reservationId={inv.reservation_id}

      />

  );
}
```

## B-2. 라우터 업데이트

라우터 파일을 읽고, 아래 Route를 **기존 Route 목록 끝에 추가**합니다.
이미 존재하는 Route는 추가하지 않습니다.

```jsx
{/* ── 신규 라우트 — 기존 Route 아래에 추가 ── */}

{/* 인보이스 */}
<Route path="/invoices"      element={<InvoiceList />} />
<Route path="/invoices/:id"  element={<InvoiceDetail />} />

{/* 테이블 */}
<Route path="/tables"        element={<TableList />} />
<Route path="/tables/:id"    element={<TableDetail />} />

{/* 리포트 */}
<Route path="/reports/daily" element={<DailyReport />} />

{/* 출퇴근 현황 */}
<Route path="/attendance"    element={<AttendanceList />} />
```
