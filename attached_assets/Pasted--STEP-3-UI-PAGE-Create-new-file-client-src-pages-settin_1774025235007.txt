### VALIDATION RULES
- Category name: required, max 100 chars, unique within same parent scope
- Max nesting depth: 2 levels only (top-level + one level of sub-types)
  → if user tries to add a sub-type under an existing sub-type, return 400 error with clear message
- tax_rate_override: must be between 0.0000 and 1.0000 (0% to 100%)
- commission_default_rate and commission_default_flat: cannot both be > 0
  → show UI validation: when one is filled, disable the other
- Soft-delete block: if category has item_count > 0, show:
  "Cannot hide this category — it has N active items. 
   Move or deactivate items first in the Menu page."
- Reorder: validate all IDs in the order array exist and belong to the same parent scope

### ERROR HANDLING
All API errors must follow the existing error response format in this codebase.
Standard error shape: { success: false, error: 'ERROR_CODE', message: '...' }
Use these specific error codes for this module:
- CATEGORY_HAS_ITEMS → 409 (cannot soft-delete)
- MAX_NESTING_DEPTH → 400 (tried to nest deeper than 2 levels)
- CATEGORY_NAME_DUPLICATE → 409 (duplicate name in same scope)
- BRANCH_ACCESS_DENIED → 403 (STORE_MANAGER accessing another branch)
- INVALID_TAX_RATE → 400 (outside 0–1 range)
- INVALID_COMMISSION → 400 (both rate and flat set simultaneously)
