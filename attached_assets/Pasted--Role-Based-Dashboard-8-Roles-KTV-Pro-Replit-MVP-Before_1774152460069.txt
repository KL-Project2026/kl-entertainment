## 🗄️ DB Query Rules

```
investor   → Query investor_reports and investor_kpi_snapshots only.
             Never access raw sessions, guests, or staff tables.

hostess    → Always filter WHERE staff_id = req.user.staffId.
             Never expose another hostess's data.

driver     → Return guest display_name + address only.
             Never include phone number or any PII.

kitchen    → Status transitions are one-way only:
             pending → preparing → ready → done
             Reject any other transition.

general    → Always filter WHERE staff_id = req.user.staffId.
```

## 🖥️ Dashboard UI Specs

### 1. Investor
```
KPI Cards (4):   Total Revenue MTD · Gross Profit · EBITDA · Active Branches
Branch Table:    Bar + GP% per branch — aggregated data only
KPI Ring Charts: Occupancy · F&B Attach Rate · Package Conversion · Hostess Utilization
Revenue Trend:   Last 7 months bar chart
```

### 2. Branch Manager
```
KPI Cards (4):   Today Revenue vs Target · Occupied Rooms · Staff on Duty · Sessions Today
Live Room Board: Real-time status chips for all rooms (Socket.io)
Alerts Panel:    Session expiring · Equipment issues · Pending approvals
Staff on Duty:   Name · Role · Current status
```

### 3. Manager
```
KPI Cards (4):   Open Folios · Pending Orders · Active Hostesses · Awaiting Approval
F&B Order Table: Room · Item · Qty · Status (live)
Hostess Board:   Name · Room · Start time · Elapsed · Commission earned
Comp Approval:   Approve / Reject buttons with reason
```

### 4. Hostess
```
Profile Header:  Name · Staff ID · Languages · Rating · Current session status
KPI Cards (4):   Today's Commission · MTD Commission · Sessions This Month · Attendance Rate
Commission:      Session · Drink · Package · Tips — itemized with bar chart
Weekly Schedule: 7-day view, today highlighted
Session History: Room · Guest name · Duration · Amount earned
```

### 5. Driver
```
Profile Header:  Name · Vehicle plate · Shift status
KPI Cards (4):   Trips Today · Distance · Driving Hours · Next Job
Job Queue:       Time-ordered list — Job ID · Guest name · Pax · Pickup → Dropoff · Status
                 (No phone number displayed)
```

### 6. Kitchen
```
KPI Cards (4):   Pending · Preparing · Ready to Serve · Completed Today
Active Orders:   Room · Item list · URGENT badge · Order time
                 [Start Prep] [Mark Ready] [Complete] action buttons
Completed Log:   Time · Room · Item summary · Avg prep time
```

### 7. Hall Staff
```
KPI Cards (4):   Open Tasks · In Progress · Completed Today · My Floor Zone
Task Queue:      Room · Description · Priority color (high=red / normal=blue / low=gray)
                 [✓ Done] button per task
Room Board:      Status grid for assigned zone rooms
```

### 8. General Staff
```
Profile Header:  Name · Role · Today's clock-in status
KPI Cards (4):   Attendance Rate · Hours This Week · Overtime This Month · Est. Net Pay
Weekly Timesheet: Day · Clock In · Clock Out · Total Hours · Status (OK / Late / Day Off)
Pay Estimate:    Base + Allowances − Deductions = Estimated Net Pay
Schedule:        Next 7 days shift plan
```
