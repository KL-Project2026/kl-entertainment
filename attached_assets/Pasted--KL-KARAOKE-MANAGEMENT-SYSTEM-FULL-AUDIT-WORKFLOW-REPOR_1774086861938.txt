## 📋 AUDIT SCOPE — TEST EVERY WORKFLOW BELOW

### MODULE 1: BRANCH & ROOM MANAGEMENT
□ Create branch → assign rooms → assign room types
□ Room status transitions: Available → Reserved → Occupied → Cleaning → Maintenance → Out-of-Order
□ Socket.io room board: does status update in real-time across multiple browser tabs?
□ Room type pricing tiers (Standard / Deluxe / VIP / VVIP) — are they branch-configurable?
□ Cleaning buffer time — is it enforced between sessions?

### MODULE 2: RESERVATION & BOOKING LIFECYCLE
□ Walk-in booking → room assignment → session start → session end
□ Advance booking → deposit tracking → confirmation WhatsApp trigger
□ Session extension logic: mid-session extend → availability check → folio update
□ Cancellation with deposit forfeit → audit log entry → commission reversal
□ No-show handling → room release → no-show flag on guest profile
□ Waitlist: add to waitlist → room becomes available → notification trigger
□ Overbooking guard: attempt double-booking same room same time → expect rejection

### MODULE 3: HOSTESS MANAGEMENT
□ Create hostess profile (direct hire) → assign to session
□ Create hostess profile (agency model) → link to agency → assign to session
□ Hostess availability check: shift schedule + existing assignments + blackout dates (all 3 must be checked simultaneously)
□ Guest-requested hostess: does it respect hostess availability?
□ Hostess session log: start time, end time, room, guest name — all populated?
□ Language/preference matching: Korean-speaking guest → Korean-speaking hostess filter

### MODULE 4: F&B POS
□ Open room session → add F&B order (Bottle / Mixer / Snack / Package)
□ Order attached to correct room folio
□ Complimentary item: manager approval workflow → logged with reason + approver
□ Split billing: 2 guests in same room, separate folios
□ Corkage fee: guest brings own bottle → corkage line item on folio
□ Last call alert: X minutes before session end → triggered correctly?
□ Mini-bar auto-post: pre-stocked items consumed → auto-posted to folio

### MODULE 5: FOLIO & INVOICING
□ Folio line items: Room charge + F&B + Hostess service + Tax + Service charge + Comps
□ Tax calculation: is it branch-configurable (SST 6% / GST 9% / VAT 7%)? NOT hardcoded?
□ Payment: Cash → receipt generated
□ Payment: E-wallet (Touch n Go / GrabPay) → receipt generated  
□ Partial payment → outstanding balance tracked correctly
□ Corporate account billing → credit terms respected → monthly invoice generation
□ PDF invoice: branding, itemized, tax breakdown — renders correctly?
□ Void/cancel folio: uses status flag (NEVER hard delete) → audit trail preserved?

### MODULE 6: COMMISSION ENGINE
□ Session commission: calculated at session CLOSE (not booking time)
□ Drink commission: per-item rate applied to confirmed F&B total
□ Package commission: flat rate per package sold
□ Agency model: agency_rate calculated separately from hostess_rate
□ Advance deduction: hostess advance taken → deducted from commission correctly
□ Commission dispute workflow: raise dispute → manager review → approved/rejected → audit log
□ Payout report: hostess commission statement generated with full breakdown

### MODULE 7: SHIFT & ATTENDANCE
□ Clock-in / clock-out → shift record created
□ Late arrival → penalty calculated → linked to commission deduction
□ Shift scheduling: weekly roster → shift swap request → approval workflow
□ Attendance affects commission eligibility (absent = no commission for that day)

### MODULE 8: INVESTOR DASHBOARD
□ Investor login → ONLY sees aggregated investor_reports table
□ Investor CANNOT access: guest names, hostess PII, staff personal data, raw transactions
□ Nightly aggregation job: raw data → investor_reports → verify data accuracy
□ KPIs visible: Revenue per Room per Hour, Hostess Utilization Rate, F&B Attach Rate, Package Conversion Rate
□ Branch comparison view: multi-branch P&L side-by-side
□ PDF export: watermarked + audit log entry on every download

### MODULE 9: RBAC & SECURITY
□ SUPER_ADMIN: full access confirmed
□ ADMIN: all branches, no platform config — test rejection of platform config access
□ STORE_MANAGER: own branch only — attempt cross-branch access → expect 403
□ HOSTESS: own sessions + own commission ONLY — attempt viewing other hostess data → expect 403
□ STAFF: room orders only — attempt viewing guest PII → expect masked/403
□ DRIVER: transfer jobs only — attempt financial data → expect 403
□ CUSTOMER: own bookings only

### MODULE 10: REAL-TIME & PERFORMANCE
□ Room board Socket.io: room status change → all connected clients update < 500ms
□ Hostess availability: multi-check (shift + assignment + blackout) completes < 300ms
□ Session extension: availability re-check + folio update atomic transaction?
□ High concurrency: 10 simultaneous room bookings → no race condition / double-booking

### MODULE 11: MULTINATIONAL READINESS
□ All UI strings: are they i18n keys (not hardcoded English)?
□ Timezone: all timestamps stored UTC → displayed in branch local timezone?
□ Non-Latin names (Chinese/Korean): stored and displayed without truncation?
□ Tax config: branch-level tax rate (not hardcoded)?
□ Date format: locale-aware (DD/MM vs YYYY-MM-DD)?
