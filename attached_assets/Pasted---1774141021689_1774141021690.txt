신규 파일 생성: /routes/admin/users.js
⚠️ 기존 routes 파일 수정 금지

[ 이 파일에 만들 API 목록 ]

GET    /api/admin/users              → 전체 사용자 목록 (Ledger 잔액 포함)
GET    /api/admin/users/:id          → 특정 사용자 상세
GET    /api/admin/users/:id/ledger   → 해당 사용자 원장 요약
POST   /api/admin/users              → 신규 사용자 생성
PUT    /api/admin/users/:id          → 사용자 정보 수정
PUT    /api/admin/users/:id/password → 패스워드 변경
DELETE /api/admin/users/:id          → 비활성화 (Soft Delete만)

[ 공통 규칙 ]

▶ 모든 API: requireRole(['super_admin']) 적용 — 다른 role은 403
▶ 패스워드: bcrypt hash 필수, 평문 저장 금지, 응답에 password_hash 절대 포함 금지
▶ DELETE: hard delete 금지 — is_active=false + deleted_at=NOW() 만
▶ 모든 변경: audit_log 테이블에 기록 (없으면 console.log로 대체)
▶ Investor role: raw ledger 금지 — v_investor_summary 뷰만 반환
▶ 테이블명: organizations(org_id), staff(id), agents(id), hostess_profiles(id)

[ GET /api/admin/users 쿼리 ]

staff 테이블 기준으로 조회.
JOIN: branches(branch_name), organizations(org_name)
LEFT JOIN: ledger_accounts(balance_cache, currency) — entity_id 기준
LEFT JOIN: hostess_profiles — staff.id = hostess_profiles.staff_id

쿼리 파라미터: search(full_name/email), role, branch_id, is_active
페이지네이션: limit(기본 20), offset

반환 시 password_hash 제거 필수.

[ GET /api/admin/users/:id/ledger ]

role에 따라 entity_id 결정:
- hostess → hostess_profiles.id 사용
- 나머지 → staff.id 사용

accountType 매핑:
hostess → 'hostess'
driver  → 'driver'
general/hall/kitchen/manager/branch_manager → 'staff'
investor → 'investor' (v_investor_summary만 반환)

반환: account 정보 + 최근 거래 10건 + 이번달 수입/공제 합계

[ POST /api/admin/users ]

필수값: full_name, email, role, password
패스워드 최소 8자 검증
이메일 중복 확인
bcrypt hash 후 저장
role = 'hostess'이면 hostess_profiles 자동 생성
ledger_accounts 자동 생성 (ON CONFLICT DO NOTHING)

[ PUT /api/admin/users/:id/password ]

body: new_password, confirm_password
일치 여부 확인
최소 8자 확인
bcrypt hash 후 UPDATE
audit_log 기록 필수

[ app.js에 추가할 코드 — 기존 코드 수정 없이 아래만 추가 ]

const adminUserRoutes = require('./routes/admin/users');
app.use('/api/admin/users', adminUserRoutes);

[ 역할 ]
사용자 목록 페이지. Settings에서 불러오는 메인 컴포넌트.

[ 화면 구성 ]

[ 기능 목록 ]

▶ 검색창: full_name / email 실시간 검색
▶ 필터: role 선택, 활성/비활성 선택
▶ 사용자 카드 클릭 → 우측에 UserDetailPanel 표시
▶ 우측 상단 "+ 새 사용자" 버튼 → 생성 폼 (inline 또는 모달)
▶ 각 사용자 카드에 role 배지 + ledger_balance 표시
▶ 페이지네이션 (20건씩)

[ role 한글 라벨 ]
super_admin → 슈퍼관리자
admin → 관리자

driver → 드라이버
general → 일반직원
