## 🔒 ABSOLUTE SAFETY RULES — 시작 전 반드시 확인

```
[RULE 1] READ BEFORE WRITE
  파일 수정 전 반드시 전체 내용을 먼저 읽어라.
  읽지 않은 파일은 절대 건드리지 마라.

[RULE 2] NO DELETION — 기존 코드 절대 삭제 금지
  기존 함수, 컴포넌트, import, 라우트, API 호출, 상태(state) 를
  단 한 줄도 삭제하지 마라.
  오직 추가(ADD) 또는 감싸기(WRAP) 방식으로만 변경하라.

[RULE 3] SYNTAX CHECK BEFORE EVERY SAVE
  파일 저장 전에 반드시 확인:
  - JSX 태그가 모두 닫혀 있는가?
  - 중괄호/괄호가 짝이 맞는가?
  - import 경로가 실제 존재하는 파일을 가리키는가?
  하나라도 의심스러우면 저장하지 말고 수정 후 재확인하라.

[RULE 4] ONE FILE AT A TIME
  파일 하나를 완전히 완료하고 검증한 뒤 다음으로 이동하라.
  에러가 나면 즉시 멈추고 보고하라. 계속 진행하지 마라.

[RULE 5] APP MUST STAY RUNNING
  각 파일 수정 후 앱이 여전히 실행되는지 확인하라.
  수정 후 앱이 죽으면 즉시 해당 파일을 원래대로 되돌려라.

[RULE 6] NEVER TOUCH THESE
  - 데이터베이스 스키마 / 마이그레이션 파일
  - .env 환경변수 파일
  - package.json (새 패키지 설치 금지)
  - 백엔드 API 라우트 파일 (읽기만 허용)
```

### 1-B. 공통 useHoverRow Hook

동일 파일 또는 `src/utils/useHoverRow.js` 생성:

```javascript
// src/utils/useHoverRow.js
import { useState, useCallback } from 'react';
import { HOVER_BG, HOVER_TRANSITION } from './constants';

/**
 * useHoverRow — manages hover state for list rows / cards
 * Usage:
 *   const { hoveredId, hoverProps } = useHoverRow();
 *   <tr {...hoverProps(item.id)} style={rowStyle(item.id)}>
 */
export function useHoverRow() {
  const [hoveredId, setHoveredId] = useState(null);

  const hoverProps = useCallback((id) => ({
    onMouseEnter: () => setHoveredId(id),
    onMouseLeave: () => setHoveredId(null),
  }), []);

  const rowStyle = useCallback((id, baseStyle = {}) => ({
    ...baseStyle,
    backgroundColor: hoveredId === id ? HOVER_BG : (baseStyle.backgroundColor || 'transparent'),
    transition: HOVER_TRANSITION,
    cursor: 'pointer',
  }), [hoveredId]);

  const cardStyle = useCallback((id, baseStyle = {}) => ({
    ...baseStyle,
    backgroundColor: hoveredId === id ? HOVER_BG : (baseStyle.backgroundColor || '#ffffff'),
    boxShadow: hoveredId === id
      ? '0 4px 16px rgba(209, 174, 56, 0.2)'
      : (baseStyle.boxShadow || '0 1px 3px rgba(0,0,0,0.05)'),
    transform: hoveredId === id ? 'translateY(-1px)' : 'none',
    transition: HOVER_TRANSITION,
    cursor: 'pointer',
  }), [hoveredId]);

  return { hoveredId, hoverProps, rowStyle, cardStyle };
}
```

import { useEffect, useState } from 'react';

function StaffDetail() {

  const [record, setRecord] = useState(null);

      .catch((err) => { setError(err.message); setLoading(false); });

  if (error)   return <div style={styles.center}>Error: {error}</div>;
  if (!record) return <div style={styles.center}>Record not found.</div>;

  return (
    <div style={styles.page}>
      {/* HEADER */}
      <div style={styles.header}>
        <button onClick={() => navigate(-1)} style={styles.backBtn}>
          ← Back
        </button>
      </div>

      {/* CONTENT — Edit 기능은 Step 4에서 추가됨 */}
      <div style={styles.title}>
        {record.name || record.full_name || `Record #${id}`}
      </div>

      <div style={styles.grid}>
        <div style={styles.card}>

              <div style={styles.label}>{key.replace(/_/g, ' ')}</div>
              <div style={styles.value}>
                {val == null ? '—' : String(val)}
              </div>
            </div>

        </div>
      </div>
    </div>
  );
}

### 4-A. Edit 기능 추가 원칙

### 4-B. 상세 페이지 Edit 추가 패턴

파일을 읽고 기존 코드를 파악한 뒤 아래 상태와 함수들을 **기존 state 선언 아래에 추가**하라:

```jsx
// ─── 기존 state 아래에 추가 ────────────────────────────────
const [isEditMode, setIsEditMode] = useState(false);
const [editData, setEditData] = useState({});
const [isSaving, setIsSaving] = useState(false);
const [saveError, setSaveError] = useState(null);

// ─── 기존 함수들 아래에 추가 ───────────────────────────────
const handleEditStart = () => {
  setEditData({ ...(record || {}) });   // 현재 record 복사
  setSaveError(null);
  setIsEditMode(true);
};

const handleEditCancel = () => {
  setIsEditMode(false);
  setEditData({});
  setSaveError(null);
};

const handleFieldChange = (key, value) => {
  setEditData((prev) => ({ ...prev, [key]: value }));
};

const handleSave = async () => {
  setIsSaving(true);
  setSaveError(null);
  try {
    // ⚠️ API 경로를 실제 엔드포인트로 교체하라
    const res = await fetch(`/api/[entity]/${id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(editData),
    });
    if (!res.ok) {
      const msg = await res.text();
      throw new Error(msg || 'Save failed');
    }
    const updated = await res.json();
    setRecord(updated);      // 기존 setRecord 함수 사용
    setIsEditMode(false);
  } catch (err) {
    setSaveError(err.message || 'Failed to save. Please try again.');
  } finally {
    setIsSaving(false);
  }
};
```

### 4-C. 헤더 버튼 영역 수정

기존 return() 안의 헤더 영역에서 Edit 버튼을 추가하라.
기존 Back 버튼이 있다면 그 옆에 추가하라. 기존 버튼은 건드리지 마라.

```jsx
{/* 기존 Back 버튼 코드는 그대로 유지 */}
<button onClick={() => navigate(-1)} style={...}>← Back</button>

{/* ↓ 아래 Edit 버튼 블록을 Back 버튼 옆(오른쪽)에 추가 */}
<div style={{ display: 'flex', gap: '8px', alignItems: 'center' }}>
  {isEditMode ? (
    <>
      {saveError && (
        <span style={{ fontSize: '13px', color: '#dc2626', marginRight: '4px' }}>
          ⚠ {saveError}
        </span>
      )}
      <button
        onClick={handleEditCancel}
        style={{
          padding: '8px 16px',
          background: '#ffffff',
          color: '#374151',
          border: '1px solid #d1d5db',
          borderRadius: '8px',
          fontSize: '14px',
          fontWeight: 500,
          cursor: 'pointer',
        }}
      >
        Cancel
      </button>
      <button
        onClick={handleSave}
        disabled={isSaving}
        style={{
          padding: '8px 16px',
          background: isSaving ? '#a5b4fc' : '#D1AE38',
          color: '#ffffff',
          border: 'none',
          borderRadius: '8px',
          fontSize: '14px',
          fontWeight: 600,
          cursor: isSaving ? 'not-allowed' : 'pointer',
        }}
      >
        {isSaving ? 'Saving...' : '✓ Save'}
      </button>
    </>
  ) : (
    <button
      onClick={handleEditStart}
      style={{
        padding: '8px 16px',
        background: '#D1AE38',
        color: '#ffffff',
        border: 'none',
        borderRadius: '8px',
        fontSize: '14px',
        fontWeight: 600,
        cursor: 'pointer',
      }}
      onMouseEnter={(e) => e.currentTarget.style.background = '#b8962e'}
      onMouseLeave={(e) => e.currentTarget.style.background = '#D1AE38'}
    >
      ✎ Edit
    </button>
  )}
</div>
```

### 4-D. 필드 표시 영역 — View/Edit 토글

기존 필드 렌더링 부분을 찾아서 아래 패턴으로 감싸라.
기존 View 렌더링은 그대로 유지하고, Edit 폼을 조건부로 앞에 추가하라.

```jsx
{/* ─── FIELDS AREA ─────────────────────────────────────────── */}
{isEditMode ? (
  // ── EDIT MODE ──────────────────────────────────────────────
  <div style={{ display: 'grid', gap: '16px' }}>
    {/*
      ⚠️ 편집 가능한 필드들을 여기에 나열하라.
      기존 record 의 실제 field key 이름을 사용하라.
      아래는 예시이므로 실제 엔티티 필드에 맞게 교체하라.
    */}

    {/* 텍스트 필드 예시 */}
    <EditField
      label="Name"
      value={editData.name || editData.full_name || ''}
      onChange={(v) => handleFieldChange('name', v)}
    />

    {/* 날짜 필드 예시 */}
    <EditField
      label="Check-in Date"
      type="date"
      value={editData.checkin_date || ''}
      onChange={(v) => handleFieldChange('checkin_date', v)}
    />

    {/* select 필드 예시 */}
    <EditField
      label="Status"
      type="select"
      value={editData.status || ''}
      options={['active', 'inactive', 'confirmed', 'cancelled']}
      // ⚠️ options는 실제 해당 엔티티의 유효한 값으로 교체
      onChange={(v) => handleFieldChange('status', v)}
    />

    {/* textarea 예시 */}
    <EditField
      label="Notes"
      type="textarea"
      value={editData.notes || editData.special_requests || ''}
      onChange={(v) => handleFieldChange('notes', v)}
    />
  </div>
) : (
  // ── VIEW MODE — 기존 렌더링 코드를 여기에 그대로 유지 ──────
  /* 기존 필드 표시 JSX 여기에 */
  null  // ← 이 null을 기존 JSX로 교체
)}
```

### 4-E. EditField 헬퍼 컴포넌트

각 상세 페이지 파일 상단에 아래 함수를 추가하라 (파일 내부 함수로):

```jsx
// ─── 파일 내 헬퍼 컴포넌트 (import 불필요) ────────────────────
// 기존 컴포넌트 함수 정의 위에 추가
const EditField = ({ label, value, type = 'text', options = [], onChange }) => (
  <div>
    <label style={{
      display: 'block',
      fontSize: '11px',
      fontWeight: 600,
      color: '#6b7280',
      textTransform: 'uppercase',
      letterSpacing: '0.07em',
      marginBottom: '6px',
    }}>
      {label}
    </label>
    {type === 'select' ? (
      <select
        value={value}
        onChange={(e) => onChange(e.target.value)}
        style={editInputStyle}
      >
        {options.map((opt) => (
          <option key={opt.value ?? opt} value={opt.value ?? opt}>
            {opt.label ?? opt}
          </option>
        ))}
      </select>
    ) : type === 'textarea' ? (
      <textarea
        value={value}
        onChange={(e) => onChange(e.target.value)}
        rows={3}
        style={{ ...editInputStyle, resize: 'vertical', height: 'auto' }}
      />
    ) : (
      <input
        type={type === 'date' ? 'date' : type === 'number' ? 'number' : 'text'}
        value={value}
        onChange={(e) => onChange(e.target.value)}
        style={editInputStyle}
      />
    )}
  </div>
);

const editInputStyle = {
  width: '100%',
  padding: '9px 12px',
  border: '1px solid #d1d5db',
  borderRadius: '8px',
  fontSize: '14px',
  color: '#111827',
  background: '#ffffff',
  outline: 'none',
  boxSizing: 'border-box',
};
```

## ⚠️ ERROR HANDLING PROTOCOL

```
에러 유형별 처리 방법:

TYPE A — JSX Syntax Error (저장 후 앱이 죽는 경우)
  → 즉시 해당 파일을 수정 전 내용으로 복원
  → 에러 메시지와 줄 번호를 보고
  → 해당 파일은 Skip 하고 계속 진행

TYPE B — Import Path Error (모듈 찾을 수 없음)
  → import 경로를 실제 파일 위치로 수정
  → src/utils/useHoverRow.js 의 실제 위치 확인 후 경로 조정

TYPE C — Route Not Found (클릭해도 이동 안 됨)
  → 라우터 파일에 해당 Route 추가
  → 상세 페이지 파일이 없으면 Step 3-C 템플릿으로 생성

TYPE D — API Endpoint Unknown (Save 시 404/500)
  → 백엔드 API 라우트 파일을 읽어서 실제 엔드포인트 확인
  → 확인된 경로로 handleSave 내 fetch URL 수정
  → 확인 불가 시: handleSave를 console.log(editData) 만 하는 
    placeholder로 대체하고 보고

TYPE E — existing onClick conflict (기존 onClick과 충돌)
  → 기존 onClick 로직을 handleRowClick 내부에 포함시켜라
  → 기존 onClick을 삭제하지 말고 handleRowClick 안에서 호출하라:
    const handleRowClick = (item) => {
      // 기존 onClick 로직 실행
      existingClickHandler(item);
      // 상세 페이지 이동
      navigate(`/entity/${item.id}`);
    };
```
